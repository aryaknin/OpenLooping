# Politique de sécurité

OpenLooping manipule des fichiers de modèles et génère du SQL. Un fichier
inconnu doit donc être traité comme une entrée non fiable.

Pour signaler une vulnérabilité, utilisez de préférence un avis de sécurité
privé GitHub (« Security advisory ») plutôt qu'une issue publique. Indiquez :

- la version concernée ;
- un fichier de reproduction minimal et anonymisé ;
- l'impact observé ;
- les étapes de reproduction ;
- toute mesure de contournement connue.

Ne joignez jamais un sujet de cours contenant des données personnelles.
