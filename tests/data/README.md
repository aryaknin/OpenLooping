# Fixtures natives minimales

Ces fichiers ont été créés comme micro-modèles contrôlés pendant l'étude du
format. Ils ne contiennent aucune donnée de cours, information personnelle,
ressource graphique ou exécutable propriétaire.

Chaque fixture isole un comportement : document vide, entité simple,
identifiant, association et variantes de cardinalité. Elles servent uniquement
aux tests de non-régression de l'import en lecture seule.
